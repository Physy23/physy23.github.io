Weirdly Filed Studio

A private, single-user application that automates the production and publishing of YouTube Shorts for the Weirdly Filed channel.

What it does

Weirdly Filed Studio is an internal production tool. It is used by one person, the owner of the Weirdly Filed YouTube channel, to manage the channel's short-form videos from finished file to published Short.

  • Production: prepares and organises short vertical videos and their titles, descriptions and tags.
  • Media files: reads and stores video files and related assets in the owner's own Google Drive.
  • Publishing: uploads videos to the owner's YouTube channel and sets their metadata and schedule through the YouTube Data API.
  • Performance: reads the channel's own statistics through the YouTube Analytics API so the owner can see how published Shorts perform.

Who it is for

The application is not a public service. It is not offered to other users, has no sign-up, and only accesses the Google account and YouTube channel of its owner after the owner signs in with Google and grants permission.

Google user data

Weirdly Filed Studio uses YouTube API Services and Google APIs only to provide the features listed above. How data is accessed, used, stored and deleted, and how to revoke access, is described in the Privacy Policy.
