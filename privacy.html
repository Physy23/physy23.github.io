Privacy Policy

Last updated: November 25, 2026

This Privacy Policy explains how Weirdly Filed Studio (“the application”, “we”) accesses, uses, stores, shares and deletes data, including data received from Google APIs. Weirdly Filed Studio is a private, single-user application that automates the production and publishing of YouTube Shorts for the Weirdly Filed YouTube channel. By signing in with Google and using the application, you agree to this Privacy Policy.

1. YouTube API Services

Weirdly Filed Studio uses YouTube API Services. By using the application, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

2. Who uses the application

The application is operated and used by a single person, the owner of the Weirdly Filed channel. It is not offered to the public. It only accesses Google account data after the account holder signs in with Google and explicitly grants permission on Google's consent screen.

3. Data the application accesses and why

YouTube Data API

  • Basic channel information (channel ID, title) to confirm which channel is connected.
  • Uploading videos to the connected channel and setting or updating their titles, descriptions, tags, thumbnails, privacy status and publishing schedule.
  • Reading the channel's own videos and their status to track what has been published.

YouTube Analytics API

  • Read-only performance metrics for the connected channel and its videos (for example views, watch time, likes and subscriber changes), used to show the owner how published Shorts perform.

Google Drive

  • Reading, creating and updating files in the owner's own Google Drive that the application works with, such as video files, thumbnails and production notes, in order to prepare videos for publishing.

The application requests only the permissions needed for these features and does not use Google user data for any other purpose.

4. How data is used

  • Data is used only to provide and improve the user-facing features described above for the owner of the connected account.
  • Data is not sold, rented or traded.
  • Data is not used for advertising, including personalised, retargeted or interest-based advertising.
  • Data is not used to determine creditworthiness or for lending purposes.
  • Data is not used to develop, improve or train generalised artificial intelligence or machine learning models.
  • No human reads Google user data except the account owner, or where required for security purposes, to comply with applicable law, or with the owner's explicit consent.

5. Limited Use disclosure

Weirdly Filed Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Sharing

Google user data is not shared with third parties. Data is only sent to Google's own services (YouTube and Google Drive) as needed to perform the actions the owner requests, such as uploading a video. Data may be disclosed only if required by law.

7. Storage and security

  • OAuth access and refresh tokens are stored privately on the owner's own device and are never published or shared.
  • Video files and production assets remain in the owner's own Google Drive and YouTube channel.
  • Data retrieved from YouTube API Services (such as video metadata and analytics metrics) may be cached locally for no longer than 30 days, after which it is refreshed from the API or deleted.
  • Data is transferred over encrypted connections (HTTPS) and is not stored on any public server. This website has no backend and does not receive or store any Google user data.

8. Cookies and this website

This website is a static documentation site. It does not use cookies, analytics, tracking scripts or forms, and it does not collect personal information. The application itself does not store, access or collect information on users' devices or browsers through cookies or similar technologies. The website is hosted on GitHub Pages; GitHub may process technical request data such as IP addresses as described in the GitHub Privacy Statement.

9. Revoking access

You can revoke Weirdly Filed Studio's access to your Google account at any time through the Google security settings page: https://security.google.com/settings/security/permissions. Once access is revoked, the application can no longer access your YouTube channel, YouTube Analytics or Google Drive data.

10. Data deletion

  • After access is revoked, all stored tokens and any locally cached data obtained through Google APIs are deleted within 7 days.
  • You can request deletion of any data held by the application at any time by emailing weirdlyfiled@proton.me. Requests are completed within 30 days at the latest.
  • Deleting data from the application does not delete videos already published on YouTube or files in Google Drive. These can be managed or deleted directly in YouTube Studio and Google Drive.

11. Children

The application is not directed to children and does not knowingly collect data from children.

12. Changes to this policy

If this policy changes, the updated version will be published on this page with a new “Last updated” date. If Google user data would be used in a new way, consent will be requested again before that happens.

13. Contact

For questions or complaints about this Privacy Policy or the application's privacy practices, contact: weirdlyfiled@proton.me
